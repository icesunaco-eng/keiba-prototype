# 保存済み架空予測の読取専用レポート
既存 `synthetic_flow/persistent.py` schema 2 のイベントSQLiteを読み取り、保存済み予測を再計算せずHTMLとして標準出力へ出す。

```sh
python report.py /path/to/synthetic-journal.sqlite > report.html
python -m unittest -v
```

架空データ専用。レース・方式・版・予測時点・候補組・架空結果の順位を表示し、繰り返し保存される累積証拠は予測IDで重複除外。証拠hash不一致・実データ・矛盾した同一ID・孤立比較は拒否。元DBはmode=roで開き、新規作成も変更もしない。出典真正性や署名は検証できない。計算の重みと確率は未学習・未較正なので確率値、金額、ROIを表示しない。注文/投票/通信なし。

内部入力・コードhash・生JSONは画面に出さない。HTMLは文字列をescapeし、スクリプト・外部通信をCSPで禁止。静的な1ページのみで検索/編集はない。実ブラウザ/iPhone描画は未検証。実運用・実予測モデルの完成ではない。

自己試験6メソッド成功。独立検証で同6件再現と追加5シナリオ成功。実データ/正式成績フラグ・孤立比較・同ID矛盾の拒否、HTMLエスケープ・上位10件・内部入力非表示・元DB不変を確認。重大欠陥なし（限定範囲）。既存保存器の実出力との結合と実ブラウザは未検証。構造不正だがhash整合のJSONでCLIの保留メッセージ外の例外となる改善余地あり。既存計算器・保存器・mainは変更しない。
