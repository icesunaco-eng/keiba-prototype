# 保存済み予測の時点比較
Y書10章「時点の比較」に対応する初段。既存の架空専用read-onlyレポートに隣接配置。

```
cd synthetic_report
python timeline.py /path/to/synthetic.sqlite --race '2140-04-11/SYN01' > timeline.html
python -m unittest -v test_timeline
```

同一レース・方式・版で時刻順にまとめ、上位10候補の追加/除外を表示。各時点の保存候補はdetailsで開閉。方式や版が異なる予測は混ぜない。同一時刻に複数予測は選択基準未定のため保留。時点ラベル24h/1h/15mを推測せず保存された時刻を表示。候補の集合差であって金額・軸の変更承認や提案ではない。理由は原保存レコードに無いため捏造せず未記録と表示。順位のみ変動は集合差には含まない。

予測・結果を再計算せず、元DBは既存report.loadのread-only経路を使用。架空限定を解除しない。実利用には実データ利用条件・時点付き入力の接続・根拠付き特徴導出と予測モデル・評価/較正・3方式対応・理由保存・本人認証と公開環境が別途必要。未較正の試算確率を実用確率とみなさない。実ブラウザ/iPhoneは未検証。注文・投票・データ取得・本番変更なし。

検証: 作者4件と独立再現4件成功。独立担当が実Journalコードで架空2時点保存→report.load→timeline表示を確認し、再計算禁止下の表示、元DB不変、外部試行0を確認。方式/レース分離、naive時刻・不正3頭・重複組拒否、HTMLエスケープ、該当なしも確認。限定重大欠陥なし。実Journal結合例は4頭で全候補4組のため集合差なし。追加/除外は別の合成試験で確認したもので、実Journalで集合差が生じたとはしない。
