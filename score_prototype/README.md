# 通常予測・最小ルール試作
既存 Y書 https://app.notion.com/p/417f1dff94dc8174b62cdb6b7c3de202 の8群採点と「点数と確率を区別」に基づく隔離試作。Y書の学習モデル・3方式・統合を完成させたものではない。

実装：入力済み8群点数→等重み平均→温度2のsoftmaxによるモデル上の勝率→Plackett-Luce順位モデルの6順序合算による三連複候補確率、降順一覧。等重み・温度2・順位仮定は計算を見せるための未学習の仮置きで、本人採用済み仕様ではない。確率は実測・較正済み的中率ではない。オッズ・期待値・資金配分・注文は計算しない。

架空4頭で平均点8/7/6/5を入力すると 1-2-3 が先頭。4頭同点なら各馬勝率1/4、4通りの三連複各1/4。3頭なら唯一の三連複1。この単体計算の一致は精度・回収率を意味しない。

入力境界：synthetic=True限定、実データは保留。全8群を本試作では必須とし欠損は補完せず保留。点数は有限0〜10、bool不可。各特徴に取得/利用可能時刻と架空出典、target_outcomeが厳密Falseを要求。予測時点は発走前、各特徴時点は予測時点以前。不明/未知フィールド/重複馬IDは保留。入力申告の真偽は検証できず、target_outcome=Falseという自己申告のみで実データ漏洩防止を保証しない。過去走からの特徴導出・実証拠検証・実データschema・時計鮮度・System統合は未実装。real_shadow常時保留を解除しない。

試験：python3 -I -B test_model.py （パスを指定しても動作）。5テストメソッド、通常/均等/3頭に加え6要求境界と11特徴境界を試験。旧受入例のNone型・target_outcome=0の問題は本試作で保留を確認。旧設計例の関数を本実装のバリデータとして使わない。

新取得・実賭け・本番変更・同着追加調査なし。固定買い目でなく入力スコアによって候補が変化する最小計算器だが、まだ実際の競馬予測能力を持つモデルとは呼ばない。
