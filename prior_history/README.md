# 根拠付き過去走の記述特徴（オフライン部品）

Y書7-1/7-2/11章の前提となる履歴の集計部品。実予測器ではない。既存の未較正scoreモデルへ自動接続しない。採用済み尺度/実モデルを置き換えない。

## 使い方
`extract(horse_id, target_race, as_of, target_start, rows)`。datetimeはtimezone必須。対象レースのtimezoneの暦日より前の走だけを採用し、available_at/observed_atも予測時点以前に限定する。呼出側は開催地を反映したtarget_startを渡す。source_refと原資料SHA256、出走ID/馬ID、発走/利用可能/観測時刻、確定着順またはNone、頭数を渡す。識別子や時刻の出典確認は呼出側の責任で、hashだけで真正性や利用許諾を保証しない。異なる訂正履歴が同一走IDにある場合は現段階で保留し、勝手に最新採用しない。

出力は過去走数、着順既知数、欠損数、1着/3着内回数、記述上の分子/母数、出典と除外理由、入力hash。欠損を5点・0着・負けとして扱わない。将来確率/10段階点数はNone、model_readyはFalse。比較対象の強さ・クラス・距離・コース・馬場・展開・斤量等の正規化は未実装。
