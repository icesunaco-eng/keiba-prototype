# 走破時間の参照補完

元PDF6頁12Rの走破時間欄は、1:34.4に続く2行が〃で、着差欄はアタマ・クビと別に記載される。従って走破時間の表示値の反復は着順同着の根拠ではない。時刻参照のみ解決し、finishはnull、dead_heat_inferred=falseを維持。

7件の旧保留は字形自体の欠落でなく、体重増減の末尾と〃が同じPDF文字断片に含まれる問題。時刻欄の固定範囲と末尾の明示〃に限定して切り出し、source_textsに元断片を保持。PDFKit側も時刻欄の矩形を狭め、数値末尾の混入を除外。全40件が独立エンジンで〃と一致。

同じページ/レース内、厳密な上→下の行順、重複IDなし、両エンジン一致、直前行の時刻確定を満たす時だけ引用。未知行・除外・順序違反で鎖を切り、他レースへ伝播しない。time_referenceに直前のpage/race/umabanを残す。

取得済み原本全171行：明示時刻130、参照時刻40、競走除外1。未解決時刻0。39自己試験PASS。独立確認待ち。PDF原本は不変、結果データ限定で予想入力・本番昇格なし。着順番号は原表の明示番号ではないため行順から自動確定していない。
