## 依頼2：ルール方式の採点尺度（正式版）

### なぜ必要か
ルール方式は、8グループを10段階で採点しています。今は Claude が作った**暫定の尺度**（`rule-v0.1-provisional`）で動かしています。
直近476レースでは、上位10組に正解が入った率が25.9%でした。学習モデルの34.8%より低いです。あいすの考える正式な尺度に差し替えたいです。

### 今の暫定版
今は、どのグループも「同じレースの中での順位」を1〜10点にしています。材料が無い馬は「未採点」です。

| グループ | 使っている材料 | 良い向き |
|---|---|---|
| 能力 | 走破指数（コース・距離ごとに標準化した時計）の近5走の最高、近3走の平均 | 高い |
| 近走 | 着順の割合（1着=0、最下位=1）の加重平均、前走 | 低い |
| 距離 | 今回の距離±200mでの着順の割合 | 低い |
| コース | 同じ競馬場、同じ芝ダでの着順の割合 | 低い |
| 馬場 | 重・不良か、それ以外かで分けた着順の割合（前日は未採点） | 低い |
| 展開・脚 | 上り3Fのレース平均との差（近3走）、最初のコーナーの位置（近3走） | 低い |
| 枠 | その競馬場・芝ダ・枠の3着内率（過去分。平均との差） | 高い |
| 斤量・騎手 | 騎手の3着内率（ベイズ縮小）、レース平均との斤量差 | 騎手は高い、斤量は軽い |

合計は、採点できたグループの単純平均です。採点できたグループの割合も残しています。

### ほしいもの
下のひな型を埋めて返してください（YAMLでも表でもよい）。

```yaml
version: rule-v1.0          # 版の名前
groups:
  ability:                  # 8グループそれぞれ
    label: 能力
    inputs: [使う材料]       # 上の表の材料、または「これが必要」という新しい材料
    scoring: |              # 1〜10点の付け方。例：レース内順位／絶対的な基準（指数が○以上なら10点…）
      …
    unscored_when: …        # 未採点にする条件
    weight: 1.0             # 合計での重み
  recent: …
  distance: …
  course: …
  going: …
  pace: …
  draw: …
  weight_rider: …
total:
  method: 重み付き平均       # 合計の出し方
  min_coverage: 0.5         # これ未満の採点割合なら「見送り（Z）」
confidence:                 # 信頼度 A/B/C/D/Z の基準（任意）
  …
```

### 守ってほしいこと
- 発走後の値（確定オッズ・人気・そのレースの着順や上り）は材料に使わない
- 今のデータで作れない材料（血統・調教など）を入れる場合は、「これから集める材料」と分けて書く
- 決まり（数式・しきい値）として書く。Claude はそのまま実装し、同じ検証にかけて結果を返す
