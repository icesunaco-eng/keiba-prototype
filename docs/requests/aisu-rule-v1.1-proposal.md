# rule-v1.1 の案と試した結果（2026-11-19・Claude → あいす）

rule-v1.0 を実データで動かすと、総合点が付く馬が約半数しかなく、成績が低く出ました。
そこで「未採点を減らす」と「総合点が無い馬の扱い」の2点だけを変えた案を作り、試しました。
**封印期間（2026-08-16〜11-15）は使っていません。** 案を決めたり直したりした期間（調整期間）は 2025-05〜2026-05、確かめた期間（確認期間）は 2026-06〜08-15 です。
どちらも発走1時間前の予想で、offline_proxy モード（候補IDと保存済みの結果版での再現）です。

## 変えたこと

| 項目 | v1.0（仕様どおり） | v1.1 の案 |
|---|---|---|
| 過去を見る期間 | 365日 | **730日** |
| 未採点にする条件 | 有効走 2走未満 | **1走から使う**。走数が少ないほど群の真ん中へ寄せる：u = (n×u_raw + 2×u0) ÷ (n + 2)。u0 は、能力は 0、それ以外は 0.5 |
| 芝ダが違う過去走 | 使わない | **重み0.5で使う**（走数にも0.5走として数える） |
| 能力の基準集団 | 同場・同芝ダ・同距離・同馬場区分（30頭・5R以上） | 足りないときは**全場・同芝ダ・同距離・同馬場区分**に広げる |
| 総合点が無い馬（三連複の確率を出すとき） | 一番弱い扱い | **そのレースの総合点の平均として扱う** |

変えていないもの：10段階の付け方、8群の重み（全部1）、総合点を出す条件（被覆0.5以上）、枠・斤量騎手の計算、使ってはいけない値。

## 結果

### 群ごとに点が付く馬の割合（2025-05〜2026-08-15）

| 群 | v1.0 | v1.1 |
|---|---|---|
| 能力 | 43% | 75% |
| 近走 | 63% | 84% |
| 距離 | 49% | 76% |
| コース | 5% | 35% |
| 馬場 | 54% | 76% |
| 展開脚 | 59% | 82% |
| 枠 | 79% | 79% |
| 斤量・騎手 | 95% | 95% |
| **総合点が付く馬** | **48%** | **61%** |

### 予想の成績

| 方式 | 調整期間 上位10組 | 調整期間 対数損失 | 確認期間 上位10組 | 確認期間 対数損失 |
|---|---|---|---|---|
| v1.0（仕様どおり） | 16.1% | 5.43 | 17.9% | 5.26 |
| v1.0 ＋ 総合点なしは平均扱い | 16.9% | 5.39 | 18.1% | 5.24 |
| v1.0 ＋ 未採点を減らす | 22.5% | 5.27 | 19.6% | 5.23 |
| **v1.1（両方）** | **22.8%** | **5.21** | **21.0%** | **5.15** |
| 参考：Claude の暫定版 v0.1 | 27.6% | 4.99 | 29.1% | 4.90 |
| 参考：学習モデル（別の実行・確認期間を含む） | 約33% | 約4.69 | – | – |

- 「上位10組」は、確率の高い順に10組を選んだとき、実際の三連複が入っていた割合です
- 対数損失は小さいほど良い指標です。全組を同じ確率とした場合は約5.7です
- 参考回収率（上位10組を100円ずつ）は、どの案も50〜75%です。レース数に対して幅が大きいので、案の良し悪しは決められません

**分かったこと**
1. 効いたのは「未採点を減らす」ほう。上位10組は、調整期間で 16% → 23%、確認期間で 18% → 20% に上がった
2. 「総合点なしは平均扱い」の効果は小さいが、どちらの期間でもプラスだった
3. それでも暫定版 v0.1 に届かない。残った差の主な理由は次の2つと考えられる
   - 総合点の条件（4群以上）を満たさない馬が39%いる。多くは新馬・出走数の少ない馬で、使える群が枠と斤量・騎手の2つだけになる。v0.1 は、使える群があれば何群でも平均を出す
   - 10段階に丸めてから足すので、差の大きさが消える。v0.1 は丸める前の順位の割合を平均している

## あいすに決めてほしいこと

1. **v1.1 の5つの変更を採用するか**（全部・一部・不採用）
2. **次に試す候補**（どれを試すか）
   - a. 総合点を、10段階に丸める前の値（群の中での順位の割合）で出す。10段階は表示だけに使う
   - b. 総合点の条件を「4群以上」から「3群以上」にする。あるいは新馬用に、調教師・騎手の新馬成績、父の新馬成績の群を足す。父と母の父は、これからのレースの出馬表から集め始めている
   - c. 8群の重みを、調整期間のデータで決める。数字8つだけなので、決まりとしての分かりやすさは残る
3. 確認期間（2026-06〜08-15）は今回見たので、次の確認には使えない。次の確認は、これから集めるレースで行う（実際の発走前検証にもなる）
