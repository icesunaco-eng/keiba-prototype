# あいす統合（方式をまとめる最終判断）の進め方の提案（2026-11-19・Claude → あいす）

## 今の材料
| 方式 | 役割 | これからのレースでの記録 |
|---|---|---|
| 学習モデル（ml_lgbm） | 予想・財布あり | 予想・配分・精算 |
| 学習＋発走前単勝オッズ（ml_market） | 予想・財布あり | 予想・配分・精算 |
| 文章AI（まむ・text_ai） | 予想・財布あり（確率を付けた場合） | 受け付けた予想だけ |
| ルール（v1.0・比較版） | 役割A：説明・確認役 | 予想は記録、配分なし。食い違いの印 |
| 市場（発走前の三連複オッズ） | 比べる相手 | 合格したオッズだけ |

過去2年の検証では、学習モデルは確定単勝オッズに上乗せできませんでした（組み合わせの重みはほぼ0）。
統合の重みを過去データで決めると、市場だけになる見込みが高いです。重みは、これからのレースで決めるのがよいと考えます。

## 提案：まとめ方
- **計算**：各方式の三連複の確率を、重み付きで掛け合わせる（対数線形の足し合わせ）。部品は `src/keiba/integrate.py`
  - 例：市場1.0・学習0.2・まむ0.2 → 市場を土台に、ほかの方式が同意する組を少し強める
- **ルール（役割A）は入れない**。食い違いの印も配分には使わない（取り決めどおり）
- **財布**：統合も、ほかの方式と同じ合格判定・同じ3配分で、別の仮想の財布にする

## 提案：重みの決め方（あいすに決めてほしい）
1. **最初の数週は重みを固定**（例：市場1.0・学習0.2・まむ0.2）。統合の財布を記録だけする
2. **8週たまったら**、それまでのレースで重みを選び直す。選び直した重みは、次の8週の新しいレースだけで確かめる（同じレースで選んで確かめない）
3. **判定の物差し**：対数損失・上位10組の的中・期待値で選んだ組の回収率。回収率の達成判定は、数週たまるまでしない

## 決めてほしいこと
- 初期の重み（上の例でよいか）
- 選び直しの間隔（8週でよいか）
- 統合の財布を、いつから記録し始めるか（まむの予想が届き始めてから、を提案）
