- **まむが上位20組などの一部だけのとき**：足りない組を「最小確率の半分」で埋めて正式な確率にはしない。参考表示に留め、配分もしない（理由を記録する）
- **入力が欠けたとき**：同じ版のまま黙って外さない。予想は記録し、配分は「未配分」にして理由を残す
  - 例：「市場：三連複オッズが合格していない（理由…）」「まむ：締切までに予想が無い」
- **ルール**：説明役のまま。統合にも配分にも入れない
- **初週**：読取の確認だけ。回収率の達成判定も実購入もしない
