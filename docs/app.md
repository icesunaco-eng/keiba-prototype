# 確認アプリ

予想・買い目・結果を iPhone 幅の画面で見て、実際に買った分を記録するためのアプリ。
**ふだんはこのMacの中だけで動く**（127.0.0.1 にだけつなぐ）。同じWi-FiのiPhoneから開くのは `--lan` を付けたときだけ（合言葉つき）。

## 動かす

- いちばんかんたん：Finder で `tools/app/確認アプリを開く.command` をダブルクリック（動いていれば開くだけ、止まっていれば起動して開く）
- Macにログインしたら自動で起動：`sh tools/app/autostart.sh install`（外すとき `uninstall`、様子は `status`。ログは `data/app/app.log`）。
  アプリが入っていないブランチに切り替わっていたら、起動せずに止まる（再起動を繰り返さない）
- 端末から：`cd ~/keiba-prototype && bin/keiba app --open`（止めるとき Ctrl+C）
- 通知：`--notify` を付けると、自信度Aで買い目があるレースと、買い目に取消馬が残っているレースを、発走20分前からMacの通知で知らせる（理由ごとに1回。同じ周回で両方なら1つにまとめる。自信度Aを知らせた後に取消が分かったら、取消をあらためて知らせる。買い目に残っている取消馬が変わったとき（例：3番に続いて4番も取消）も、もう一度知らせる。自動起動では付けている）
- 検証データ（過去の封印期間）で画面を確かめたいとき：`bin/keiba app --mode check`（画面のメニュー → 表示の設定 でも切り替えられる）
- 購入記録を試すとき（本物の記録に混ぜない）：`bin/keiba app --store /tmp/試し.sqlite`

## 画面の地図

1画面1テーマ。詳しいものは「›」で次のページへ。よく使う4つは下のタブ、たまに使うものは右上のメニュー（≡）。

- レース：一覧（時点の切替・開催場・その日のまとめ・警告「取消あり／チェック×／古いオッズ／発走済み」）→ 詳細（学習・ルール・まむ・統合の切替、印、買い目、根拠、1タップで見送り）
  → 全頭の評価（ルールの8項目からの一言）／買い目のチェック（公開前チェック・偏り・予想が変わる条件）／方式くらべ／時点の変化／購入を記録
- これからのレースの一覧と詳細は1分ごとに読み直す（表示の設定で止められる）。収集が30分以上止まっていたら一覧の上に出す
- 履歴：すべて・購入記録・見送り → 履歴の詳細（予想の変化・メモ・購入記録）→ 記録の編集
- 結果：まとめ（仮想と実購入を分ける・直近50/100/500R/全部）→ 方式ごと／条件別（距離・芝ダ・クラス・月別）／見送りの振り返り
- 改善：今の版と候補 → 新旧くらべ（2つの版を、両方にあるレースだけでくらべる。たかむねの判断を記録。運用の版は変えない）／比較の詳細／変更履歴
- メニュー：データの状態／購入記録の一覧（CSV書き出し）／表示の設定／このアプリについて

## データの扱い

- 予想の台帳（`data/ledger.sqlite`）と表は**読むだけ**。予想を作り直したり書き換えたりしない
- 書き込むのは本人の購入記録とメモだけ。`data/app/purchases.sqlite` に**追記**（直すときは新しい版の行を足す、取り消しは「取り消し」の行を足す。UPDATE/DELETE はトリガーで止める）
- もう1つ、`data/app/race_meta.json` にレースの頭数・発走時刻の控えを書く（収集の予定表は7日で整理されるので、外れた後も過去のレースの結果がそろっているか確かめるため）。台帳・収集の原本には書かない。控えが無いレースの結果は保留になる
- 購入記録（実際のお金）は、仮想の財布（模擬）とは別に集計する
- 印（◎○★）は、その方式の3着内確率の順。推論は「推論」、取得時刻などは「事実」、合否の理由などは「注意」のラベルで分けて出す
- 記録が無いところは「—」と件数0を出し、数字を作らない

## 買い目のチェック（公開前チェック）

取消・除外の馬が買い目に残っていない／組の形（3頭・出走している馬番）／同じ組の重複が無い／100円単位・1レース上限 ¥10,000／
点数が10点以内／三連複オッズの確認が合格／出馬表の新しさ。✓＝合格、×＝不合格、—＝判定できない・対象なし。
偏り（全部の組に入っている馬、1つの組に金額が集中、◎が入っていない）と、予想が変わる条件（★と4番手の差など）は「推論」「注意」として出す。

## 守り

- Host がこのMac（127.0.0.1／localhost）以外なら断る（`--lan` のときは、このMacのWi-Fiの住所と「名前.local」も受ける）
- 書き込み（POST）は、起動ごとに作る合言葉が合い、よそのページからの送信でないときだけ受け付ける
- JavaScript は使わない。外部のファイル（フォント・CDN）も読み込まない

## iPhone から見る（同じWi-Fi・合言葉つき）

1. `~/keiba-prototype/.env`（git には上げない）に `KEIBA_APP_PASSPHRASE=10文字以上の合言葉` を書く
2. `sh tools/app/autostart.sh install --lan`（自動起動で）または `bin/keiba app --lan --notify` で起動。表示された `http://…:8765/` を iPhone の Safari で開く
3. このMac以外からは、合言葉を入れるまで何も見せない。5回まちがえると10分止める。合言葉を変えると、前のログインは使えなくなる
- 通信は暗号化していない（家のWi-Fiの中だけで使う前提）。外出先から見るのは Cloudflare の段で別に決める
- 初回は macOS が「受け入れますか」と聞くことがある
