# 確認アプリ

予想・買い目・結果を iPhone 幅の画面で見て、実際に買った分を記録するためのアプリ。
**ふだんはこのMacの中だけで動く**（127.0.0.1 にだけつなぐ）。同じWi-FiのiPhoneから開くのは `--lan` を付けたときだけ（合言葉つき）。

## 動かす

- いちばんかんたん：Finder で `tools/app/確認アプリを開く.command` をダブルクリック（動いていれば開くだけ、止まっていれば起動して開く）
- Macにログインしたら自動で起動：`sh tools/app/autostart.sh install`（外すとき `uninstall`、様子は `status`。ログは `data/app/app.log`）。
  アプリが入っていないブランチに切り替わっていたら、起動せずに止まる（再起動を繰り返さない）
- 端末から：`cd ~/keiba-prototype && bin/keiba app --open`（止めるとき Ctrl+C）
- 通知：`--notify` を付けると、自信度Aで買い目があるレースと、買い目に取消馬が残っているレースを、発走20分前からMacの通知で知らせる（理由ごとに1回。同じ周回で両方なら1つにまとめる。自信度Aを知らせた後に取消が分かったら、取消をあらためて知らせる。買い目に残っている取消馬が変わったとき（例：3番に続いて4番も取消）も、もう一度知らせる。自動起動では付けている）
- 検証データ（過去の封印期間）で画面を確かめたいとき：`bin/keiba app --mode check`（画面のメニュー → 表示の設定 でも切り替えられる）
- 購入記録を試すとき（本物の記録に混ぜない）：`bin/keiba app --store /tmp/試し.sqlite`

## 画面の地図

1画面1テーマ。詳しいものは「›」で次のページへ。よく使う4つは下のタブ、たまに使うものは右上のメニュー（≡）。

- レース：一覧（時点の切替・開催場・その日のまとめ・警告「取消あり／チェック×／古いオッズ／発走済み」）→ 詳細（学習・ルール・まむ・統合の切替、印、買い目、根拠、1タップで見送り）
  → 全頭の評価（ルールの8項目からの一言）／買い目のチェック（公開前チェック・偏り・予想が変わる条件）／方式くらべ／時点の変化／購入を記録
- これからのレースの一覧と詳細は1分ごとに読み直す（表示の設定で止められる）。収集が30分以上止まっていたら一覧の上に出す
- 履歴：すべて・購入記録・見送り → 履歴の詳細（予想の変化・メモ・購入記録）→ 記録の編集
- 結果：まとめ（仮想と実購入を分ける・直近50/100/500R/全部）→ 方式ごと／条件別（距離・芝ダ・クラス・月別）／見送りの振り返り
- 改善：今の版と候補 → 新旧くらべ（2つの版を、両方にあるレースだけでくらべる。たかむねの判断を記録。運用の版は変えない）／比較の詳細／変更履歴
- メニュー：データの状態／購入記録の一覧（CSV書き出し）／表示の設定／このアプリについて

## データの扱い

- 予想の台帳（`data/ledger.sqlite`）と表は**読むだけ**。予想を作り直したり書き換えたりしない
- 書き込むのは本人の購入記録とメモだけ。`data/app/purchases.sqlite` に**追記**（直すときは新しい版の行を足す、取り消しは「取り消し」の行を足す。UPDATE/DELETE はトリガーで止める）
- 過去のレース：収集は終わった開催を7日で予定表から外す。外す前に頭数・発走時刻などを `data/live/races_archive.jsonl` に1行ずつ追記して残す（収集が書く。確認アプリは読むだけ）。確認アプリはこの記録で、予定表から外れたレースの結果がそろっているかを確かめる。記録が無い・値がおかしいレースは結果を保留にする（読めた行の数から頭数を推測しない）
- 結果のページが途中で切れていたら（最後の `</html>` まで届いていない）、何も読まずに結果待ちのままにする。三連複の払戻が100円未満と読めたときも確定しない（数字が途中で切れた読取とみなす）。収集は「取得済み」にせず、結果の窓（発走30分後〜6時間後）の間は次の回に取り直す
- レースの取りやめ：収集は、結果がまだのレース（予定表に残っている過去7日〜明日）があるとき、30分に1回 JRA のニュースの月別一覧（`https://www.jra.go.jp/news/YYYYMM/`。前日の月も）を見て、見出しが決まった形のお知らせだけを `data/live/cancellations.jsonl` に追記する（一覧のページは原本として保存）。読む形（実物の例）：「本日【2月7日（土曜）】の東京競馬は第8レース以降を取りやめ」「〜は第4レースを取りやめ」「〜の東京競馬第9レースの取りやめおよび…」「本日／明日【…】の〜競馬（および〜競馬）は開催を中止します」「第2回中京競馬第7日第2競走の取りやめ」（日付の無い形は、回次・日次が同じ予定表のレースから日付を決める。決まらなければ書かない）。「開催中止に伴う指定席の取扱い」「夜間発売を取りやめ」「前日発売を取りやめ」のような関連のお知らせは拾わない。お知らせがあり、結果のページが無いか最後まで届いたページに結果の行が1つも無いレースだけを、全額返還（レース取りやめ）として精算する。結果の行があれば本当の結果を使う。見出しの形が違うお知らせは読めないので、そのレースは保留のまま
  - ただし「開催を中止」（番号の無いお知らせ）は途中のレースの後にも出るので、お知らせを見つけたのが発走前のレースだけすぐ返還。発走後に見つけたレースは、結果の窓（発走の6時間後）が過ぎても結果のページに行が無いときだけ返還。結果のページも無ければ保留
  - 仮想財布の返還は発走時刻を過ぎてから書く（15分前の最後の配分で精算するため。精算は書き直せない）
- JRA の開催一覧を取れない：知っているレースの取得・予想・精算は続け、次の回に更新し直す（知らせは続けて失敗している間1回だけ）
- 予想・精算が途中で止まった：次の回に、精算が0件でも月次を作り直す
- 特払い（三連複の的中者がいない。全員に100円につき70円）の精算は未対応：100円未満の払戻は保留
- 同じ失敗は直るまで1回だけ知らせる（別の失敗は知らせる）。精算だけの同じ失敗が続くときは30分おきにやり直す
- 見回り（collect tick）は1つずつ：前の回が動いている間に始めた回は何もせずに終わる（`data/live/tick.lock`）
- 精算は予想1行の3配分をまとめて書く：途中で失敗したら1つも確定しない（払戻の欠けで待つのは配分ごと）
- 予想・精算の失敗：そのレース・方式だけ飛ばして、ほかは続ける（非数・無限の予想は台帳に書かない）。次の回にやり直し、知らせは続けて失敗している間1回だけ
- 数え方（2026-11-22 決定）：仮想の成績・画面の予想・月次は「その時点の材料（出馬表 → 三連複オッズか未発表の記録）を取った後、締切＋10分までに最初に保存した版」だけ（取れなかった時点は締切の後に作ったものに限る）（`src/keiba/official.py`）。台帳の行は消さずに読むときに選ぶ。1レース×1方式で1つ（15分前、無ければ1時間前）。締切＋10分より後に保存した予想・発走時刻が分からない予想は数えず、件数を画面と月次に出す（材料を取る前に保存した予想も同じ）
- 発走時刻が変わったとき（2026-11-23 決定）：締切は予想を保存した時点で分かっていた発走時刻で決め、後から動かさない（`data/live/post_times.jsonl`、追記だけ）。最終の発走時刻より後に保存したものはどの場合も数えない。記録できない間は予想を作らない
- 各時点の予想・まむへの入力：その時点の取得が終わってから作る。取れなければ締切を過ぎたときに、ある材料で作る（前の時点の出馬表で先に作って固定しない）
- 予想・精算：新しいページ・取りやめ・前の回の失敗のどれかがあれば動き、成功するまで5分ごとにやり直す。発走後のレースの予想は、コードの版が変わっても作らない
- クラス：レース名（例：「3歳以上1勝クラス」「2歳未勝利」）から 新馬・未勝利・1勝〜3勝クラス・オープン を読む（予定表から外れたレースも、残した記録のレース名から読む）
- 結果の精算（実購入・仮想財布とも）は、予定の頭数が分かり、全部の行を重複なく読めて、買った的中組の払戻が読めたときだけ行う。そうでなければ待つ（台帳は書き直せないので、仮想財布は「未精算」を書かない）。完走なのに着順が空欄の馬がいるときも待つ
- 収集が台帳を書いている間は読めないことがある。そのときは前に読んだデータで表示を続け（画面の上に知らせが出る）、起動直後でまだ読めていなければ「読み込み中」を出して10秒ごとに読み直す。記録の保存は「少し待ってもう一度」と出して保存しない
- 購入記録（実際のお金）は、仮想の財布（模擬）とは別に集計する
- 印（◎○★）は、その方式の3着内確率の順。推論は「推論」、取得時刻などは「事実」、合否の理由などは「注意」のラベルで分けて出す
- 記録が無いところは「—」と件数0を出し、数字を作らない

## 買い目のチェック（公開前チェック）

取消・除外の馬が買い目に残っていない／組の形（3頭・出走している馬番）／同じ組の重複が無い／100円単位・1レース上限 ¥10,000／
点数が10点以内／三連複オッズの確認が合格／出馬表の新しさ。✓＝合格、×＝不合格、—＝判定できない・対象なし。
偏り（全部の組に入っている馬、1つの組に金額が集中、◎が入っていない）と、予想が変わる条件（★と4番手の差など）は「推論」「注意」として出す。

## 守り

- Host がこのMac（127.0.0.1／localhost）以外なら断る（`--lan` のときは、このMacのWi-Fiの住所と「名前.local」も受ける）
- 書き込み（POST）は、起動ごとに作る合言葉が合い、よそのページからの送信でないときだけ受け付ける
- JavaScript は使わない。外部のファイル（フォント・CDN）も読み込まない

## iPhone から見る（同じWi-Fi・合言葉つき）

1. `~/keiba-prototype/.env`（git には上げない）に `KEIBA_APP_PASSPHRASE=10文字以上の合言葉` を書く
2. `sh tools/app/autostart.sh install --lan`（自動起動で）または `bin/keiba app --lan --notify` で起動。表示された `http://…:8765/` を iPhone の Safari で開く
3. このMac以外からは、合言葉を入れるまで何も見せない。5回まちがえると10分止める。合言葉を変えると、前のログインは使えなくなる
- 通信は暗号化していない（家のWi-Fiの中だけで使う前提）。外出先から見るのは Cloudflare の段で別に決める
- 初回は macOS が「受け入れますか」と聞くことがある
