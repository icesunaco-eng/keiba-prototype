## 結果（封印期間・1時間前・876R）
| 方式 | 上位10組に正解が入った率 | 参考回収率（上位10組を100円ずつ。払戻が分かる798R） |

| 学習モデル | 35.1% | 78%（95%幅 66〜90%） |
| 比較：ロジスティック回帰 | 33.3% | 80%（67〜93%） |
| ルール方式・あいす v1.0 | 11.7% | 49%（29〜77%） |

| 比較：人気順（**確定オッズ**を使うので予想には使えない） | 42.8% | 76% |
| 全組を同じ確率とした場合 | 約2〜3%（頭数による） | – |

- 学習モデルは、でたらめよりはっきり当たるが、市場（人気順）には届かない。回収率は100%未満
- **ルール v1.0 が低い理由**：仕様どおり「同じ芝ダ・過去365日に有効走2走以上」などを満たさない馬は総合点なし（順位対象外）。総合点が付く馬は約半数で、封印期間の38%のレースは全体が Z。三連複の確率を出すとき、総合点なしの馬を一番弱い扱いにしているので、新馬や休み明けの馬が来ると外れる。総合点が付いた馬どうしの順位は暫定版並みに効いている（着順との相関 −0.38）
- ルール v1.0 は仕様の「offline_proxy」モード（候補IDと保存済みの結果版での再現）。発走前検証ではない
- 封印期間を見た後なので、v1.0 の扱いは変えていない（仕様の「評価期間を見て調整しない」）

### 収集を動かす（HEROINES で1回だけ）
```
cd ~/keiba-prototype && bin/keiba collect install
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.heroines.keiba-collect.plist
```
止めるとき：`launchctl bootout gui/$(id -u)/com.heroines.keiba-collect`。Mac がスリープ中は動かないので、開催日は起こしておく。
取ったページは `data/live/`（git 管理外・手元だけ。JRAの著作物なので私的使用の範囲で使う）。
