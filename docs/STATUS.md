# 現在地（2026-11-19 更新）

## ひとことで
2年分の統合版（全6,893R）で、**取込 → 予想 → 保存 → 精算 → 表示を実データで一周させた。**
学習モデルは「でたらめ」よりははっきり当たるが、**市場（確定オッズの人気順）に届かない**。
しかも、市場と組み合わせても上乗せが無かった（確定単勝オッズに無い情報を、今の学習モデルはほとんど持っていない）。
買う判断に使える段階ではない。**本当の判定は、これから集める発走前オッズでの「仮想の財布」で行う**（今週末から自動で記録）。

## 検証のしかた

- **封印期間**：直近3か月（2026-08-16〜11-15・876R）。最後に1回だけ予想して評価

## 結果（封印期間・1時間前・876R）
| 方式 | 上位10組に正解が入った率 | 参考回収率（上位10組を100円ずつ。払戻が分かる798R） |
|---|---|---|
| 学習モデル | 35.1% | 78%（95%幅 66〜90%） |
| 学習＋市場（確定単勝オッズで近似） | 42.8% | 76%（68〜85%）。v=0 で市場だけと同じ |
| 比較：ロジスティック回帰 | 33.3% | 80%（67〜93%） |
| ルール方式・あいす v1.0 | 11.7% | 49%（29〜77%） |
| ルール方式・案 v1.1 | 20.6% | 67%（45〜98%） |
| ルール方式・暫定 v0.1 | 26.0% | 67% |
| 比較：人気順（**確定オッズ**を使うので予想には使えない） | 42.8% | 76%（68〜85%） |
| 全組を同じ確率とした場合 | 約2〜3%（頭数による） | – |

- **市場との組み合わせ**：点 = log(市場推定確率) + v × 学習モデル。v を較正期間で選ぶと、検証の16か月中8か月が 0、残りも 0.025〜0.1、封印期間は 0。今の学習モデルは確定単勝オッズに無い情報をほとんど持たない。ただし確定オッズは締切直前の情報まで含むので、発走前（1時間前・15分前）のオッズでは結果が変わりうる。これから集めるデータで確かめる
- 参考回収率（オッズを見ずに上位10組を買う）は、どの方式も100%未満で幅も広い。110%の判定には使えない。判定は、発走前の三連複オッズで期待値が1を超える組だけを買う「仮想の財布」で行う
- **ルール v1.0 が低い理由**：総合点が付く馬が約半数（仕様の未採点条件）。案 v1.1 で改善したが、暫定版には届かない（`docs/requests/aisu-rule-v1.1-proposal.md`）
- ルール方式は「offline_proxy」モード（候補IDと保存済みの結果版での再現）。発走前検証ではない
